## A. 압축 풀기와 Python

1. ZIP을 다운로드한 뒤 마우스 오른쪽 버튼을 눌러 **모두 압축 풀기**를 선택하세요. ZIP 안에서 바로 실행하지 말고, 압축을 푼 뒤 모든 파일을 같은 폴더에 두세요.
2. Python 3.10 이상이 필요합니다. 이미 설치했다면 다시 설치할 필요는 없습니다. [Windows용 Python 다운로드](https://www.python.org/downloads/windows/)
   - 설치 화면에 `Add python.exe to PATH` 옵션이 나오면 선택하세요.
   - 조직 PC에서 설치가 차단되면 관리자에게 설치를 요청하세요.
3. `01_check_python.bat`을 실행하세요. `Python 3.x.x`가 표시되고 버전이 3.10 이상이면 준비된 것입니다.
   - `Python` 한 단어만 나오거나 Python을 찾을 수 없다는 메시지가 나오면 설치를 확인하세요.
   - 설치한 뒤에는 터미널을 닫고 다시 실행하세요.

## B. Notion 준비

Notion 연결은 처음 한 번만 설정하면 됩니다.

1. Notion 워크스페이스에 빈 일반 페이지를 만드세요. 예를 들어 `Paper Bot Home`이라는 페이지를 만들 수 있습니다. 이 페이지 아래에 Paper Bot 데이터베이스가 생성됩니다. 데이터베이스나 열을 미리 만들 필요는 없습니다.
2. [Notion 연결 관리](https://www.notion.so/my-integrations)에서 새 내부 연결(Internal connection 또는 Internal integration)을 만드세요. 연결과 부모 페이지는 같은 워크스페이스에 있어야 합니다.
3. 연결 권한에서 다음 항목을 켜고 저장하세요.
   - 콘텐츠 읽기(Read content)
   - 콘텐츠 삽입(Insert content)
   - 콘텐츠 업데이트(Update content)

   댓글 및 사용자 이메일 권한은 필요하지 않습니다.
4. 내부 연결 토큰(Internal Integration Secret 또는 token)을 복사하세요. 이 토큰은 `02_setup_notion.bat`에만 입력하고 다른 사람과 공유하지 마세요.
5. 만든 부모 페이지로 돌아가 오른쪽 위 `…` → **연결(Connections)** → **연결 추가(Add connections)**를 선택한 뒤 방금 만든 연결을 추가하세요. Notion 화면에 따라 `더 보기(More)` 아래에 메뉴가 있을 수 있습니다. 연결이 보이지 않으면 부모 페이지와 연결이 같은 워크스페이스인지 확인하세요.
6. 부모 페이지의 **링크 복사**를 눌러 페이지 주소를 복사하세요. 데이터베이스나 논문 페이지의 주소가 아니라 일반 부모 페이지 링크가 필요합니다. 페이지를 웹에 게시할 필요는 없습니다.

## C. 처음 설정하기

아래 순서로 실행하세요.

1. `01_check_python.bat` — Python 버전을 확인합니다.
2. `02_setup_notion.bat` — Notion 토큰과 부모 페이지 링크를 입력합니다. 토큰 입력 중 글자가 화면에 표시되지 않는 것은 정상입니다. 부모 페이지 읽기를 확인한 뒤 설정이 저장됩니다.
3. `03_test_notion.bat` — 부모 페이지 아래에 `[논문 봇] Notion 연결 테스트` 페이지가 생기는지 확인합니다. 이 테스트는 실제 논문 검색이나 AI 호출을 하지 않습니다.
4. `04_create_paper_table.bat` — 부모 페이지 아래에 Paper Bot 표를 만듭니다.
5. `05_edit_keywords.bat` — `config.json`을 메모장에서 엽니다. 검색어와 관심 분야를 수정한 뒤 저장하세요. 자세한 내용은 D 절에 있습니다.
6. `06_setup_ai_optional.bat` — AI 요약이 필요할 때만 설정합니다.
   - `1`은 Gemini, `2`는 OpenAI입니다. 공개 PDF 분석은 Gemini 연결에서 지원합니다.
   - Gemini API 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 준비할 수 있습니다.
   - 설정 중 조회한 모델 목록에서 사용할 모델을 선택하세요. 목록에 표시된다고 무료 사용이나 PDF 입력이 보장되는 것은 아닙니다.
   - [Gemini 요금 안내](https://ai.google.dev/gemini-api/docs/pricing)에서 본인 모델과 프로젝트의 무료 등급을 확인하세요.
   - 연결 테스트에서 `y`를 입력하면 API 요청 한 번을 보냅니다. 성공해야 설정이 저장됩니다.
   - OpenAI API 사용은 ChatGPT 구독과 별도로 과금될 수 있습니다.
7. `07_setup_pdf_search_optional.bat` — Gemini로 공개 PDF 검색을 할 때 설정을 권장합니다. 이메일을 입력하면 Unpaywall 검색을 추가합니다. 생략하면 Crossref에 등록된 PDF 정보만 확인합니다.
8. `08_run_paper_bot.bat` — 수집을 시작합니다. AI가 연결되어 있으면 실행 모드에서 `2`를 선택해야 요약이 포함됩니다. Enter만 누르면 기본 수집 모드입니다. 처음에는 실행 시간 10분, 검색 간격 5분, AI 요청 한도 1회로 확인해 보세요.
9. `09_collect_without_ai.bat` — AI 호출 없이 논문 정보만 수집합니다. AI를 설정하지 않은 경우 이 파일을 사용하면 됩니다.

## D. 검색 설정

기본 설정은 multi-omics, AI, mass spectrometry imaging 관련 검색어를 포함합니다. `config.json`에서 다음 항목을 수정할 수 있습니다.

- `keywords`: 검색어 목록. 예: `"multi-omics machine learning"`
- `interest`: AI 요약에서 살펴볼 관심 분야. 한국어로 작성해도 됩니다.
- `from_date`: 검색 시작 날짜. 예: `"2025-01-01"`
- `max_papers`: 한 번의 검색 주기에서 처리할 논문 수. 1~20, 기본값 3입니다.
- `candidates_per_keyword`: 검색어별 검색 후보 수. 1~100, 기본값 30입니다.
- `exclude_keywords`: 추가로 제외할 검색어. 제외하지 않으려면 `[]`로 둡니다. MDPI는 별도로 제외됩니다.

`config.json`은 JSON 형식입니다. 큰따옴표와 대괄호를 유지하고, 마지막 항목 뒤에는 쉼표를 넣지 마세요. `max_papers`는 실행 전체 논문 수가 아니라 **검색 주기당 처리 상한**입니다.

## E. Notion 표

표 이름은 **Paper Bot**이며 다음 열을 사용합니다.

| 열 | 용도 |
|---|---|
| Read | 읽은 논문을 직접 체크 |
| Paper | 논문명. 눌러서 논문 페이지를 엽니다. |
| Publish Date | 발행 날짜 |
| Journal | 저널명 |
| DOI | 논문 DOI 링크 |
| Corresponding author | 확인된 교신저자. 확인할 수 없으면 `확인 필요`로 표시됩니다. |
| Keyword | 논문을 찾은 검색어 |
| 수집일시 | 한국 시간 기준 수집 시각 |

요약은 표의 열이 아니라 각 논문 페이지 안에 저장됩니다. 논문 제목을 눌러 페이지를 연 뒤 `Paper Bot AI 요약 · 공개 PDF 기반` 또는 `Paper Bot AI 요약 · 초록 기반` 항목을 펼쳐 확인하세요.

PDF나 PDF 상태 열은 없습니다. 분석에 사용한 PDF 주소는 논문 페이지의 요약에 표시됩니다. 표의 열 순서는 자동으로 설정되지만, 적용되지 않았다면 Notion에서 표 보기를 만들고 위 순서대로 열을 배치하면 됩니다. 원하면 Read가 체크되지 않은 논문만 보이도록 필터를 추가할 수 있습니다.

## G. 논문 및 AI 분석 범위

Gemini는 CC BY 또는 CC0 라이선스를 확인하고 로그인 없이 내려받을 수 있는 공개 PDF를 우선 분석합니다. 파일은 최대 12 MiB까지, 논문당 최대 3개 주소를 확인합니다. 보충자료는 별도로 수집하지 않습니다.

학교 계정이나 구독 자료는 사용하지 않습니다. 공개 PDF를 찾지 못하면 초록을 분석하고, 초록도 없으면 분석을 보류합니다. 따라서 모든 논문의 전문을 확보하지는 않습니다. PDF 전체를 AI에 전달하더라도 모델이 모든 내용을 정확히 판독한다고 보장할 수는 없습니다.

API 오류나 사용 한도 초과 시에는 실패로 기록하고 유료 AI로 자동 전환하지 않습니다. 기존 논문 분석은 PDF를 읽지 못한 뒤 초록 분석을 재시도하는 경우 최대 두 번의 API 요청이 발생할 수 있습니다.

## H. 자주 발생하는 문제

- **401**: Notion 토큰을 확인하고 필요하면 02번으로 다시 설정하세요.
- **403**: Notion 연결의 콘텐츠 읽기·삽입·업데이트 권한을 확인하세요.
- **404(Notion)**: 부모 페이지와 연결이 같은 워크스페이스인지, 페이지에 연결을 추가했는지 확인하세요.
- **404(Gemini)**: 06번을 다시 실행하고 현재 사용할 수 있는 모델을 선택하세요.
- **429**: API 요청 한도나 호출 속도를 확인하고 요청 횟수를 줄이세요.
- **요약이 없음**: 08번 실행 시 AI 요약 모드인 `2`를 선택했는지 확인하세요. 기존 논문에는 90번을 사용할 수 있습니다.
- **기존 초록 요약 유지**: 봇이 허용된 공개 PDF를 확보하지 못한 경우입니다. PDF 주소, 라이선스, 다운로드 제한을 확인하세요. 07번 설정도 확인할 수 있습니다.
- **전송 보류 또는 pending**: Notion에 이미 저장됐을 수 있습니다. 페이지를 확인하기 전에 `state.sqlite3`를 삭제하지 마세요.
- **JSON 오류**: `config.json` 문법을 확인하세요. `config.example.json`을 참고할 수 있습니다.

기존 논문의 PDF를 다시 확인하려면 프로그램 폴더에서 다음 명령을 실행할 수 있습니다.

# Paper Bot 백그라운드 예약 실행 추가팩

기존 Paper Bot 폴더에 추가팩 파일만 복사하면 됩니다. `background_tasks.py`는 `run_python.bat`, `paper_bot.py`와 같은 폴더에 넣어주세요. 기존 설정이나 수집 기록은 건드리지 않습니다.

먼저 기존 프로그램에서 Notion 연결과 검색이 잘 되는지 확인하세요. AI 요약을 예약하려면 Gemini 또는 OpenAI 설정도 필요합니다.

| 번호 | 파일 | 기능 |
|---|---|---|
| 10 | `10_setup_background_schedule.bat` | 예약 시간과 실행 모드 설정 |
| 11 | `11_run_background_now.bat` | 지금 바로 시험 실행 |
| 12 | `12_background_status_and_logs.bat` | 실행 상태와 로그 확인 |
| 13 | `13_remove_background_schedule.bat` | 예약 해제 |

## 예약 등록하기

`10_setup_background_schedule.bat`을 실행하고 매일 실행할 시각을 입력하세요. 예를 들어 `09:00`이나 `09:00,18:00`처럼 입력하면 됩니다.

실행 모드는 `1`이 논문 정보만 수집, `2`가 AI 요약 포함입니다. AI 요약을 원하면 `2`를 선택하세요. 한 번에 사용할 AI 요청 횟수도 설정할 수 있습니다. 처음에는 1~3회 정도로 시작하는 걸 권합니다.

예약이 등록되면 실행 창을 닫아도 됩니다. 예약된 시각마다 검색을 한 번 실행합니다. 계속 검색을 반복하는 방식은 아닙니다.

## 먼저 시험해 보기

예약을 등록한 뒤 `11_run_background_now.bat`으로 한 번 시험 실행해 보세요. AI 모드라면 API 사용량이 발생할 수 있습니다.

“실행 요청 완료”가 표시되면 `12_background_status_and_logs.bat`을 실행해 결과를 확인하세요. 자세한 기록은 프로그램 폴더의 `output/scheduler` 안에 저장됩니다. Notion에도 논문이 추가됐는지 확인해 주세요.

## 알아둘 점

PC가 켜져 있고 Windows에 로그인된 상태여야 합니다. 화면을 잠가도 되지만, 로그아웃하거나 컴퓨터가 꺼져 있거나 절전 중이면 실행되지 않습니다. 예약 시간은 Windows에 설정된 시간대를 따릅니다.

예약 시간을 바꾸거나 AI 모드를 변경하려면 10번을 다시 실행하세요. 예약을 그만 쓰려면 13번을 실행하면 됩니다.
