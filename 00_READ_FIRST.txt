Paper Bot v2.0.0-beta.6 — 처음부터 실행하기

이 파일부터 읽으세요. Windows용 번호 실행 파일이 포함되어 있습니다.
추가 Python 패키지나 서버는 필요 없습니다. 인터넷 연결은 필요합니다.
처음 설치: 준비 → 01 → Notion 설정 → 02 → 03 → 04 → 05 → (선택 06·07) → 08
매일 실행: 08만 실행. AI 없는 수집만 원하면 09.
90번대는 필요한 경우에만 쓰는 도구이며, 순서대로 전부 실행하지 않습니다.

A. 압축 풀기와 Python
1) ZIP을 다운로드한 뒤 마우스 오른쪽 → 모두 압축 풀기.
   ZIP 안에서 바로 실행하지 마세요. 모든 파일을 같은 폴더에 유지하세요.
2) Python 3.10 이상이 필요합니다. 이미 설치했다면 재설치할 필요 없습니다.
   설치: https://www.python.org/downloads/windows/
   설치 화면에 Add python.exe to PATH가 있으면 선택하세요.
   조직 PC에서 설치가 차단되면 관리자에게 설치를 요청하세요.
3) 01_check_python.bat을 실행합니다.
   Python 3.x.x가 나오고 3.10 이상이면 성공입니다.
   'Python' 한 단어만 나오거나 찾을 수 없다는 메시지는 정상 설치 확인이 아닙니다.
   설치 후 터미널을 닫고 다시 실행하세요.

B. Notion 준비 — 프로그램 실행 전에 한 번만
1) 본인 Notion 워크스페이스에 빈 '일반 페이지'를 만드세요.
   이름 예: Paper Bot Home. 이 페이지 아래에 Paper Bot 데이터베이스가 생성됩니다.
   사용자가 데이터베이스나 열을 미리 만들 필요는 없습니다.
2) https://www.notion.so/my-integrations 를 열어 개발자 연결 관리 화면으로 이동합니다.
   화면이 바뀌었다면 Notion 설정 → 연결 또는 개발자 메뉴를 이용하세요.
   새 내부 연결(Internal connection / Internal integration)을 만드세요.
   이름 예: Paper Bot Local. 위 페이지와 같은 워크스페이스를 선택합니다.
   이 안내서는 내부 연결 토큰 방식입니다. 공개 OAuth 앱 설정은 필요 없습니다.
3) Capabilities / 권한에서 콘텐츠 읽기(Read content), 삽입(Insert content),
   업데이트(Update content)를 켜고 저장합니다.
   댓글·사용자 이메일 권한은 이 프로그램에 필요하지 않습니다.
4) 내부 연결 토큰(Internal Integration Secret / token)을 복사합니다.
   아래 02 실행창에만 입력하세요. 채팅, GitHub, 공유 문서에 붙여 넣지 마세요.
5) 1번에서 만든 부모 페이지로 돌아갑니다.
   오른쪽 위 … → 연결(Connections) → 연결 추가(Add connections) → Paper Bot Local 선택.
   새 UI에서는 … → 더 보기(More) 안에 연결 메뉴가 있을 수 있습니다.
   목록에 없으면 연결과 페이지가 같은 워크스페이스인지 확인하세요.
   조직 워크스페이스에서 연결 생성/추가가 제한되면 관리자에게 요청하세요.
6) 부모 페이지의 '링크 복사'로 일반 페이지 링크를 복사합니다.
   표의 보기 링크나 개별 논문 링크가 아닙니다. 웹에 게시(Publish)할 필요는 없습니다.

C. 번호대로 최초 설정
01_check_python.bat
  Python 버전 확인. A 절 참고.
02_setup_notion.bat
  내부 연결 토큰과 부모 페이지 링크를 입력합니다.
  토큰은 붙여 넣어도 화면에 보이지 않는 것이 정상입니다. Enter를 누르세요.
  부모 페이지 읽기 확인 후 .env에 저장됩니다.
03_test_notion.bat
  부모 페이지 아래에 '[논문 봇] Notion 연결 테스트' 페이지가 생성되는지 확인합니다.
  실제 논문이나 AI 호출이 아닙니다. 기존 테스트를 전송했다면 중복 방지로 건너뜁니다.
04_create_paper_table.bat
  부모 페이지 아래에 Paper Bot 표를 자동 생성합니다.
  기존 표가 있으면 열 구성을 갱신할 수 있으므로 기존 사용자도 안내를 확인하세요.
05_edit_keywords.bat
  config.json을 메모장에서 엽니다. 처음에는 예시 설정을 복사해 만듭니다.
  아래 D 절을 참고해 수정하고 Ctrl+S로 저장한 뒤 창을 닫으세요.
06_setup_ai_optional.bat — AI 요약이 필요한 사람만
  1=Gemini 또는 2=OpenAI를 선택합니다. 공개 PDF 분석은 Gemini 연결에서 지원합니다.
  Gemini 키: https://aistudio.google.com/apikey
  API 키를 입력하고 실제 조회된 모델 목록에서 번호 또는 ID를 선택합니다.
  https://ai.google.dev/gemini-api/docs/pricing 에서 본인 모델·프로젝트의 무료 등급을 확인하세요.
  목록에 있다는 사실만으로 무료 사용이나 PDF 지원이 보장되지는 않습니다.
  테스트 질문에 y를 입력하면 API 요청 1회를 보내고 성공 시 연결 설정을 저장합니다.
  OpenAI API는 별도 과금될 수 있습니다. ChatGPT 구독과는 별개입니다.
  무료 등급도 사용량 제한이 있습니다. 키/모델이 틀리면 요약은 실행되지 않습니다.
07_setup_pdf_search_optional.bat — Gemini PDF 분석 시 권장
  본인 이메일을 입력하면 Unpaywall 공개 PDF 검색을 추가합니다.
  이메일은 Unpaywall API의 연락처 매개변수로 전달됩니다.
  생략하면 Crossref에 등록된 PDF/라이선스 정보만 탐색합니다.
08_run_paper_bot.bat — 설정 완료 후 평소 실행
  총 실행 시간(분), 검색 완료 후 대기 간격(분)을 입력합니다.
  처음에는 총 10분, 간격 5분으로 확인하세요.
  AI가 연결되어 있다면 1=기본 수집, 2=AI 요약 포함을 선택합니다.
  Enter만 누르면 기본 수집이므로, 요약을 원하면 반드시 2를 입력하세요.
  처음 AI 요청 한도는 1을 권장합니다. 한도 소진 시 시간 전에도 종료됩니다.
  Notion 표에 논문이 생기고 제목을 열었을 때 요약이 보이면 성공입니다.
09_collect_without_ai.bat — 08 대신 선택
  AI API를 호출하지 않고 논문 정보만 수집합니다. 06·07을 생략해도 됩니다.

D. 검색 설정 예시
config.json의 기본 관심 분야는 multi-omics, AI, mass spectrometry imaging입니다.
- keywords: 검색어 목록. 예: "multi-omics machine learning"
- interest: AI 요약에서 특히 살펴볼 관심 맥락. 한국어 사용 가능.
- from_date: 논문 검색 시작 날짜. 예: "2025-01-01"
- max_papers: 한 번의 검색 주기에 처리할 최대 논문 수(1~20). 기본 3.
- candidates_per_keyword: 검색어별 후보 수(1~100). 기본 30.
- exclude_keywords: 제외할 단어 목록. 비워두려면 []. MDPI는 별도로 항상 제외합니다.
JSON 형식이므로 큰따옴표, 쉼표, 대괄호를 유지하고 마지막 항목 뒤에는 쉼표를 넣지 마세요.
max_papers는 실행 전체 한도가 아닙니다. 시간 동안 검색을 반복하며 새 논문을 처리합니다.
새 논문이 없으면 아무 행도 추가되지 않을 수 있습니다.

E. Notion 표 사용법
표 이름: Paper Bot
열 순서:
1. Read — 읽었으면 직접 체크
2. Paper — 논문명. 클릭해서 페이지 열기
3. Publish Date — 메타데이터의 발행 날짜
4. Journal — 저널명
5. DOI — 원문으로 이동하는 DOI 링크
6. Corresponding author — 명시적으로 확인된 교신저자, 미제공 시 '확인 필요'
7. Keyword — 수집 시 검색어
8. 수집일시 — 한국시간 기준 수집 시각

PDF, PDF 상태 열은 없습니다. 분석에 사용한 PDF 주소는 해당 논문 페이지의 요약 안에 표시됩니다.
Paper 제목을 클릭하고 'Paper Bot AI 요약 · 공개 PDF 기반' 또는 '초록 기반' 접기를 펼치세요.
PDF 요약에는 분석 범위, 출처 링크, 라이선스와 연구 내용·결과·한계·검토 질문이 들어갑니다.
표 보기 자동 설정이 실패하면 Notion에서 표(Table) 보기를 추가하고 위 순서로 열을 끌어 놓으세요.
원하면 Read가 체크되지 않은 항목만 보이도록 필터를 추가하고 수집일시 내림차순으로 정렬하세요.
프로그램이 찾는 열 이름은 임의로 바꾸지 않는 것이 좋습니다.

이번 ZIP에는 개인 설정·수집 이력이 포함되지 않습니다.
기존 연결이 정상이라면 02·03·06·07을 다시 설정할 필요 없습니다. 평소에는 08을 실행하세요.

G. 이 버전의 동작 범위
공개 PDF는 CC BY/CC0 라이선스와 주소를 확인하고 로그인 없이 확보할 수 있을 때 분석합니다.
PDF 최대 12 MiB, 논문당 다운로드 후보 최대 3개. 별도 보충자료는 수집하지 않습니다.
학교 계정·구독 로그인은 사용하지 않습니다. 모든 논문의 전문을 확보하는 도구는 아닙니다.
PDF 전체 파일을 Gemini에 전달하지만 모델의 정확한 해석이나 완전한 판독을 보장하지 않습니다.
전문 미확보 시 초록으로 분석하며 이유를 표시합니다. 초록도 없으면 분석을 보류합니다.
API 오류·한도 초과는 분석 실패로 남깁니다. 유료 공급자로 자동 전환하지 않습니다.
기존 논문 처리 한 번당 API 최대 2회(PDF 판독 불가 후 초록 재시도 포함)일 수 있습니다.
PC가 켜져 있고 절전 상태가 아니어야 합니다. 실행 창을 닫으면 중단됩니다.
중지: 실행 창에서 Ctrl+C. 자동 시작·서비스·백그라운드 예약 실행 기능은 포함되지 않습니다.
실행 시간은 새 작업 시작 기준입니다. 진행 중 요청은 완료/타임아웃까지 더 걸릴 수 있습니다.
동시에 봇을 여러 개 실행하지 마세요. 잠금 오류라면 기존 실행을 먼저 종료하세요.

H. 자주 만나는 문제
401: Notion 토큰 확인 → 02 재설정. 페이지 링크나 모델 ID를 토큰 칸에 넣지 마세요.
403: 연결의 콘텐츠 읽기·삽입·업데이트 권한 확인.
404(Notion): 같은 워크스페이스인지, 부모 페이지에 연결을 추가했는지 확인.
404(Gemini): 06에서 모델 목록을 다시 조회하고 사용 가능한 모델 선택.
429: API 사용 한도/호출 속도 초과. 잠시 후 요청 횟수를 줄여 실행하고 제공업체 한도 확인.
요약이 없음: 08에서 모드 2를 선택했는지 확인. 기존 논문에는 90을 사용하세요.
기존 초록 유지: PDF 링크/허용 라이선스/다운로드 조건 미충족. 07 설정과 출력 사유 확인.
일정 시간이 지나 다시 시도하려면 프로그램 폴더 터미널에서:
  python ai_tools.py existing --upgrade --retry-unavailable
전송 보류/pending: 이미 Notion에 저장됐을 수 있습니다. 페이지 확인 없이 state.sqlite3를 삭제하지 마세요.
JSON 오류: config.json의 문법 확인. config.example.json을 참고하세요.
